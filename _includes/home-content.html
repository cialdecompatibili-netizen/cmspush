Cos'è cmspush

Un CMS visuale per Jekyll
che salva direttamente su GitHub.

cmspush è un pannello di amministrazione in un singolo file HTML. Nessuna installazione, nessun backend, nessun hosting aggiuntivo. Si integra nel tuo repo Jekyll e pubblica articoli, pagine e impostazioni via GitHub API. Aggiornamenti automatici con un click, come WordPress — ma su GitHub Pages.

01

Scrivi e pubblica

Editor visuale per articoli e pagine. Salva direttamente nel repo GitHub via API. Nessun terminale.

02

Cambia tema

9 skin Minimal Mistakes selezionabili dal pannello. Il sito si aggiorna in 60 secondi.

03

Aggiornamenti automatici

Bottone di aggiornamento nel pannello. Nuove versioni disponibili con un click, senza toccare il codice.
